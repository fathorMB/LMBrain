# First-class findings

`FINDING-*` records durable cross-spec truth; it is not a specification, work authorization, review verdict, diagnostic, or GitHub issue.

Artifacts live in exactly one status directory: `open`, `planned`, `deferred`, `resolved`, `accepted-risk`, or `superseded`. Create and transition them through the semantic `finding_*` MCP tools. Do not promote ordinary review bullets automatically and do not treat a done target spec as resolution evidence.

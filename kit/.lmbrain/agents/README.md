# Agent Profiles

These documents describe reusable specialist roles. They are not running agents and do not trigger automatic spawning.

`title` is the formal role label. `mnemonic_name`, when present, is the human conversational label the Project Lead can use in handoffs and summaries.

The Project Lead recommends a profile and the relevant spec. The user starts the agent manually unless they explicitly authorize the Lead to dispatch named specs under the model-selection policy in `contract/effort_tags.md`.
